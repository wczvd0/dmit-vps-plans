BUILDERv2 是全场性价比最扎眼的一档：$14.9/月拿到 2 核 2GB 和 2TB 流量，代价是带宽只有 30Mbps。

## 常见问题

**续费价格怎么确认？**
下单前把计费周期在月付、季付、半年付、年付之间切换一遍，每个周期都会显示对应的实付总额，按总额除以月数比较。拿不准就先买最短周期，用一个月再决定要不要续长期。

**想先试一个月行不行？**
月付档直接买一个月就行，不必一上来就年付。洛杉矶的 BUILDERv2、STARTER、MINI、MICROv3、MEDIUMv2 和香港四档都是月付，无限流量档的 uMINI 及以上也是月付。

**无限流量会被限速吗？**
不限量指的是流量额度，带宽按你买的那一档固定，uBUILDER 是 10Mbps，uMINI 是 30Mbps，以此类推。不是跑满就降速，而是一开始就在这个速度上。

**1GB 内存能跑什么？**
一个 WordPress 加数据库基本就占满了，再加个缓存插件会紧。要同时跑站点、数据库和几个后台服务，从 2GB 起步更稳，香港 pvm.n2.micro（$29.9/月）或洛杉矶 BUILDERv2（$14.9/月）都是 2GB。

**洛杉矶和香港能中途换机房吗？**
机房是下单时选定的，换机房等于重新开一台。
